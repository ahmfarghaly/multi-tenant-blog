# Multi-Tenant Blog

This project demonstrates Hibernate multitenant support in a blog application.

## Key Features
- Shows how to configure Hibernate for multitenancy
- Provides examples for handling multiple tenants in a single application
- Implements tenant separation at the database level
- Includes basic blog functionality to illustrate multitenant operations

## Technology Stack
- Java
- Hibernate
- Spring Framework
- ReactJS for frontend demonstration

## Purpose
- Serve as a reference for implementing multitenancy with Hibernate
- Help developers understand and apply multitenant patterns in Java applications
